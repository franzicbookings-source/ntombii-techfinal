# Two Lights — the Ntombii Tech brand film

A 60-second, 16:9 brand film built in [Remotion](https://www.remotion.dev/) (React). Everything is code: the lights, objects, typography, logo build, edit and timing. The score is generated by `audio/make_audio.py`. Read `BRIEF.md` for the story, the treatments considered and the beat sheet, and `CREDITS.md` for references and asset credits.

This folder is a separate project. The website build, type check, lint and tests ignore it.

## Rerender

```sh
cd film
npm install                      # Remotion 4.0.535, React 19
node scripts/prepare-assets.mjs  # copies the logo, font, atmosphere image, Moyandi screenshot and two project clips from ../public
npm run studio                   # optional: scrub the film in the browser
npm run render                   # out/ntombii-two-lights-master.mp4 (1920×1080, 30 fps, H.264 CRF 12, AAC 320k)
```

Website version and poster (needs ffmpeg):

```sh
ffmpeg -i out/ntombii-two-lights-master.mp4 -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p -profile:v high -movflags +faststart -c:a aac -b:a 128k ../public/videos/brand-film/ntombii-two-lights-1080p.mp4
npx remotion still src/index.ts TwoLights out/poster.png --frame 440
```

To reuse a Chrome that is already installed (for example in a locked-down container), set `REMOTION_BROWSER_EXECUTABLE=/path/to/chrome-headless-shell`. `node scripts/stills.mjs out/stills 0 440 1100` renders any frames as PNGs from one bundle.

## Change things

- **Timing:** every cue lives in `src/timeline.json` (30 fps; 1 beat = 15 frames, 1 bar = 60 frames at 120 BPM). Picture and sound both read it, so move a cue and re-run the music.
- **Words:** all on-screen copy is in `src/Film.tsx`, set in Aeonik from the website. Keep it to what the About page states.
- **Projects:** the two clips in "Today" come from `public/videos/work/` (made by `scripts/motion/make-video.cjs` in the website repo). Swap the file names and labels in `src/Film.tsx`.
- **Music:** `python3 audio/make_audio.py` (needs `pip install mido numpy scipy`, `apt install fluidsynth fluid-soundfont-gm` and ffmpeg) writes `public/audio/score.mp3`, the file the film uses. The warm electric piano is Sabelo's voice and the glockenspiel is Sthembile's.
- **Colours:** `src/theme.ts`. Navy and slate are the website's; the warm and cool lights are the film's own.

## Website embed (not published)

`public/videos/brand-film/` in the website holds the web MP4 and the poster. When you're ready to publish, an About-page embed is:

```html
<video controls playsinline preload="none" poster="/videos/brand-film/ntombii-two-lights-poster.webp" width="1920" height="1080">
  <source src="/videos/brand-film/ntombii-two-lights-1080p.mp4" type="video/mp4">
</video>
```

The film has no narration; every story beat is on-screen copy, so no captions file is needed. If it autoplays, keep it muted and give visitors a pause control.

## Verified (21 November 2026)

- Master: 1920×1080, 30 fps, 1800 frames (60.000 s), H.264 High CRF 12 (about 9.8 Mbps) with AAC 320k, 72 MB. Not committed; it's large and can be rerendered.
- Website version: `public/videos/brand-film/ntombii-two-lights-1080p.mp4`, 1080p H.264 CRF 23 with fast start, AAC 128k, 8.1 MB.
- Sound: −15.8 LUFS integrated, −1.5 dBTP before encoding. Every hit lands within 10 ms of its picture cue. True silence for the final second.
- Picture: no black frames. The brightest frame (the reveal at 0:38) averages 162/255; the reveal is a single flash, not repeated flashing.
- Legibility: checked at 1080p and at phone width (390 px). The main lines are 76–124 px at 1080p.
- Not checked: listening on speakers. The build environment has no audio playback, so the mix was checked by loudness measurements and spectrograms. Give it one listen on a phone and on headphones before publishing.
