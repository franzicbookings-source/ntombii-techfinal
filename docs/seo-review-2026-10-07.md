## Google and AI search

Google's generative search features use the same core SEO foundations: accessible pages, helpful original content, clear structure and accurate business details. Google explicitly says it does not use llms.txt as special AI search markup. There is no special schema that guarantees an AI recommendation.

OpenAI identifies OAI-SearchBot as its search crawler. Ntombii Tech's current robots.txt allows it. GPTBot relates to model training and is a separate control; enabling training is not a requirement for appearing in ChatGPT Search. Website changes can support discovery by search-enabled AI tools, but cannot guarantee mentions in every model's answers.

Use consistent public facts, specific project evidence and genuine third-party recognition. Check search and enquiry performance regularly instead of assuming an added keyword or file will produce first place.
