# Content illustrations, 24 October 2026

The owner requested illustrated icons instead of decorative numbering on Our Work and anywhere else on the website. Replaced visible sequence markers in both project stories, shared service offerings and process sections, the services index, the KZN website page, regional print enquiries and the contact process. The Work index itself had no numbered markers. All existing headings and body copy remain intact, apart from redundant Browse/Choose/Enquire labels beside the old numerals.

`components/content-illustration.tsx` owns twelve small inline SVG illustrations in the existing slate palette. Content selects the subject; fixed contexts select it explicitly. An understated tonal shape and consistent outlines keep them coherent without a new dependency, downloaded font or image request. Icons are hidden from assistive technology because the adjacent copy supplies the meaning. Process lists retain list semantics. Functional carousel announcements, real prices, quantities, age, dates and contact details remain unchanged. Article contents already displayed without numbers and were left alone.

Validation: TypeScript, production build and all 14 rendered tests pass. Browser evidence is in /workspace/ntombii-site-qa/content-icons/. Checks cover 13 routes at 320, 390 and 1440px for no decorative numeral labels, icon rendering, overflow and runtime errors. Accessibility scans compare representative edited pages against the current live version to distinguish existing contrast issues in project breadcrumbs/captions from regressions. No React effects, state, new client boundary or runtime dependency were introduced.
